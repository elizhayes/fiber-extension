# fiber-extension
A Chrome extension to tell you how much fiber is in the recipe you're looking at. 

## setup
In order to look up nutrition facts from the USDA database, you must configure a USDA API key. You can request a key here: https://fdc.nal.usda.gov/api-key-signup. Copy and paste your key in the "Settings" section of the extension. 

In order to use the LLM fallback (optional), you must configure an Anthropic API key. You can request one here: https://platform.claude.com/settings/keys. Copy and paste your key in the "Settings" section of the extension.
